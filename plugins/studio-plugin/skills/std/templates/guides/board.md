# Board guide

How this repository's videos look. The visual director reads it.

- Brand: name, accent color and logo come from `.claude/studio/brand.json`.
- Images and text cards are decided at the script stage. Board changes only the attributes of the blocks already in
  the script (adding, removing or swapping a block changes the content approved at ① and ②).
- An image the source analysis does not allow (scope and credits) is reported, not removed: the script stage
  replaces it with `::title[…]` or a text card.
- One visual idea per scene; keep subtitles readable (s2v check must pass).
