# MJ-SAMECAUSE — same root cause? (J-S1, stagnation role axis)
Two blocking reasons from consecutive attempts of the same role. `same` when the later one restates
the same file/AC/concern (even reworded) — the redo did not address it. A new or different concern,
even in the same area, is `different`. When unsure, `unsure` (read as different).
