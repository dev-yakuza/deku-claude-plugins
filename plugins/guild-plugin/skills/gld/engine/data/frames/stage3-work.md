- **Golden reasons.** `golden_reasons` has one entry for every baseline image, snapshot or comparison setting this attempt added, changed or deleted — `path` and `reason`: `intended-change` (the Issue changes that screen), `bug-fix` (the old image showed the bug), `new-case` (a new visual case), `moved` (same image, new place), `needs-regeneration` (it must change but you could not regenerate it here — say why in `note`). The engine builds the change ledger from git and rejects a result that leaves one out; a reason given in an earlier attempt for the same file content carries over. Empty list when you touched none.
