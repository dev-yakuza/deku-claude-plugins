The engine added this review from the plugin step catalog because the change touches build, CI, deployment or configuration. Review those changes on the current branch. The diff of the whole branch is in `review.diff` (engine folder); the intent is `analysis.md`. Read the diff fully and open each changed build, workflow, container and configuration file in its current state.

Check id `infra-safety`: `pass` when the change keeps builds reproducible (pinned versions, lockfiles), keeps CI checks as strict as before (no removed job, skipped step or loosened condition the Issue did not ask for), exposes no secret, widens no permission or network access without a reason, and has a way back; `fail` otherwise — then give each problem as a finding. A change that deploys, releases, applies infrastructure or deletes a resource when merged is also reported in `irreversible` with its code; the engine decides what happens with it.
