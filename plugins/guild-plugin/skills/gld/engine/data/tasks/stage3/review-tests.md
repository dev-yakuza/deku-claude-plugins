The checks this step must give are the ones listed under "Required checks" below; besides `test-quality` they may be:
- `regression-proof` (bug template) — `pass` when the regression test written by the reproduce step was red for the reason the Issue states (read `repro-evidence.md`: the failing assertion, not a compile error, a missing import, a timeout or a flaky wait), states the correct behaviour, and would fail again if the fix were reverted; `fail` otherwise.
- `net-public-behavior` (refactor templates with a safety net) — `pass` when every `(safety net)` case of `test-cases.md` has a test in the new safety-net files, those tests use the public interface only (no private functions, no mocks of the code's own internals, no structural snapshots), and each would fail if its behaviour broke; `fail` otherwise. A behaviour that looks like a bug must not be pinned: report it in `discoveries` (`kind: bug`).
